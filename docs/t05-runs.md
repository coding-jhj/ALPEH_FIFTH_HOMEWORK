# T05 검사 실행 회차 기록

세는 법: `npm run verify:brief` 1회 실행 = 1회차.
10개 중 하나라도 FAIL이면 그 회차를 **오류 1**로 센다 (T05-C25).

| 회차 | 시각 (KST) | 작업자 | 통과 | 첫 실패 ID | 오류 회차 | 누적 요청수 |
|---|---|---|---|---|---|---|
| 0 | 2026-08-31 20:46 | 기준선(구현 전) | 0/10 | T05-T01 | — (착수 전, 집계 제외) | 0 |

0회차는 `src/lib/brief.ts`가 아직 없는 상태의 기준선입니다.
검사 러너 자체가 정상 동작하고 10개 전부 FAIL을 정확히 보고하는지 확인한 것으로,
A·B 오류 회차 집계에는 포함하지 않습니다.
